# Original ZUOYA definition

`ZUOYA_GMK70.json` is an unchanged copy of the vendor's `ZUOYA GMK70.json` supplied alongside stock V13 in the December 16, 2024 upgrade package. Only the filename differs.

SHA-256: `e878d51b9c1bdbf182feb48fa892ad822c9b4b8ff94f42ebe6b5e7fd0ba94789`.

Load this definition in VIA's Design tab. It describes the device and controls, not a saved keymap. It has seven named custom keys; remaining numbered custom slots keep the stock firmware meanings documented in `../../docs/STOCK-COMPATIBILITY.md`.

Do not change this file to accommodate firmware differences. Adapt the firmware and add regression coverage instead.
